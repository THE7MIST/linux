===============================
IMPORTANT EXAM NOTES
===============================

1. Screenshots required:
   - DHCP Role installation
   - Scope creation wizard
   - Address Pool
   - Address Leases
   - Client IP (ipconfig)

2. Common mistakes:
   - Forgot to activate scope
   - Wrong IP range
   - DNS not added
   - Gateway missing
   - Server using dynamic IP (WRONG)

3. Troubleshooting:
   - Restart DHCP service
   - Disable/Enable client adapter
   - Check firewall blocking DHCP
   - Run: ipconfig /renew again
