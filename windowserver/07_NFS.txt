------------------------------------------------------------
PART 1: INSTALL NFS ROLE ON WINDOWS SERVER
------------------------------------------------------------

Open Server Manager
→ Click [Manage] (top right)
→ Click [Add Roles and Features]

→ Before You Begin screen
→ Click [Next]

→ Installation Type
→ Select [Role-based or feature-based installation]
→ Click [Next]

→ Server Selection
→ Select your server (e.g., MASTER)
→ Click [Next]

→ Server Roles
→ Expand [File and Storage Services]
    → Expand [File and iSCSI Services]
        → Check [Server for NFS]
            → Popup appears → Click [Add Features]

→ Click [Next]

→ Features
→ (No changes required)
→ Click [Next]

→ Confirmation
→ Check [Restart the destination server automatically if required]
→ Click [Install]

→ Wait for installation to complete
→ Click [Close]

------------------------------------------------------------
PART 2: CREATE NFS SHARE (GUI CONFIGURATION)
------------------------------------------------------------

Open Server Manager
→ Left panel → Click [File and Storage Services]
→ Click [Shares]

→ Top right → Click [Tasks]
→ Click [New Share]

→ Select Profile
→ Choose [NFS Share – Quick]
→ Click [Next]

→ Share Location
→ Select [Type a custom path]
→ Enter: C:\sharing_NFS
→ Click [Next]

→ Share Name
→ Share name: mychoice
→ (Auto remote path shown as \\MASTER\sharing_NFS)
→ Click [Next]

------------------------------------------------------------
PART 3: LINUX CLIENT (CENTOS) CONFIGURATION
------------------------------------------------------------

Open Terminal

→ Install NFS utilities:
# dnf install -y nfs-utils

→ Create mount directory:
# mkdir /mnt/win-nfs

→ Mount NFS share:
# mount -t nfs 192.168.119.128:/sharing_NFS /mnt/win-nfs

→ Verify mount:
# df -h

→ (Optional persistent mount)
Edit fstab:
# nano /etc/fstab

Add line:
192.168.119.128:/sharing_NFS   /mnt/win-nfs   nfs   defaults   0 0

→ Apply:
# mount -a

NOTES (IMPORTANT FOR EXAM)
------------------------------------------------------------

- Use AUTH_SYS for simple setup
- Avoid enabling root access unless required
- Ensure firewall allows NFS (port 2049)
- Ensure correct IP mapping between client & server
- Always verify mount using df -h
- Use correct path format:
    Linux: server_ip:/share
    Windows: \\server\share
